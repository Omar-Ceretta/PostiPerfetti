# Sicurezza di «PostiPerfetti»

## Versioni supportate

«PostiPerfetti» è alla sua prima distribuzione pubblica stabile.

Le correzioni di sicurezza vengono applicate alla versione corrente del progetto e alle Release pubbliche attuali. 
Eventuali vecchie copie di sviluppo NON continueranno ad essere supportate.

## Segnalare un problema di sicurezza

Se scopri un problema che può compromettere la sicurezza del programma, dei dati locali o della procedura di installazione, è preferibile segnalarlo senza pubblicare immediatamente dettagli che potrebbero facilitare un abuso.

Se la segnalazione può essere descritta senza informazioni sensibili, è possibile usare gli strumenti di contatto indicati nel repository.

Per problemi ordinari, malfunzionamenti o richieste di miglioramento si può invece ricorrere alle normali Issue del progetto.

## Dati da NON allegare

Una segnalazione non deve contenere dati reali degli studenti.

In particolare, non pubblicare:

- file-classe reali;
- copie dello Storico;
- Report o fogli Excel con nomi degli studenti;
- log contenenti informazioni che non desideri rendere pubbliche;
- percorsi locali o altri dati personali non necessari alla diagnosi.

Quando occorre riprodurre un problema, utilizza preferibilmente i file di esempio distribuiti con il programma oppure dati completamente fittizi.

## Ambito

Sono considerate rilevanti per la sicurezza anche le anomalie che riguardano:

- lettura, scrittura o perdita inattesa dei dati locali;
- esecuzione di contenuti non previsti;
- installer, launcher o disinstaller;
- verifica dell'integrità dei pacchetti di Release;
- gestione delle dipendenze Python;
- esposizione involontaria di informazioni attraverso diagnostica o log.
