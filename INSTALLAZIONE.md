In breve, per gli utenti **Linux**, l'installazione richiede solo Python 3 e due righe in un terminale:

```bash
wget https://raw.githubusercontent.com/Omar-Ceretta/PostiPerfetti/main/install.sh
bash install.sh
```

Tutti i dettagli (requisiti, primo avvio, aggiornamenti, risoluzione problemi) sono nella pagina Release collegata qui sopra.
